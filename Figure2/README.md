# Figure 2

This folder contains the data and scripts used to reproduce Figure 2.

## Files

- SKX_HSP_N4.m: script for plotting the band structures
- SKX_Chern.m: script for plotting the corresponding Chern numbers
- tm_N4.txt, kt_whole.txt, dt.txt: processed data files required by the MATLAB scripts. These files are automatically loaded when running the scripts.

## Requirements

- MATLAB (tested with R2023)

## How to reproduce

1. Open MATLAB in this directory.
2. Run the band structure script: SKX_HSP_N4
3. Run the Chern number script: SKX_Chern

Both scripts will automatically load the provided data files and generate the corresponding figures.
