## Figure 4 and Figure 5
This folder contains the data and scripts used to reproduce Figure 4 and Figure 5.

### Description
The local Chern marker along the lines `a`, `b` and `c` shown in Figs. 3, and the local Chern marker along the central 12 sites of lines `b` and `c`.

### Files

- `LCM_line.m`: script for plotting the local Chern marker along specified lines.

### Requirements

- MATLAB (tested with R2023)

### How to reproduce

1. Open MATLAB in this directory.
2. Run the script: `LCM_line`

### Parameter settings

- `row_idx = 1`  → Figure 4(a)
- `row_idx = 22` → Figure 4(b) and Figure 5(a)
- `row_idx = 23` → Figure 4(c) and Figure 5(b)
