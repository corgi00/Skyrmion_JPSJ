## Figure 8

This folder contains the script used to reproduce Figure 8.

### Description

Dependence of the Bott index on the number of occupied states.

### Files

- `SKX_BOTT_occ.m`: script for plotting Figure 8(a)
- `SKX_BOTT_gama_occ.m`: script for plotting Figure 8(b)

### Requirements

- MATLAB (tested with R2023)

### How to reproduce

1. Open MATLAB in this directory.
2. Run the script: `SKX_BOTT_occ` to generate Figure 8(a)
3. Run the script: `SKX_BOTT_gama_occ` to generate Figure 8(b)
