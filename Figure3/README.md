# Figure 3

This folder contains the data and scripts used to reproduce Figure 3.

## Description

Distribution of the local Chern marker in an $L=11$ skyrmion supercell with unit cell containing $4 \times 4$ spins at $J/t=10$.

## Files

- SKX_LCM_nbyn.m: script for plotting the local Chern marker distribution

## Requirements

- MATLAB (tested with R2023)

## How to reproduce

1. Open MATLAB in this directory.
2. Run the script: SKX_LCM_nbyn
