## Figure 6

This folder contains script used to reproduce Figure 6.

### Description

Convergence of the local Chern marker in the central region and the Bott index under open boundary conditions for the topologically nontrivial phase.

### Files

- `SKX_LCM_average.m`: script for plotting the convergence of the local Chern marker in the central region
- `SKX_BOTT_average.m`: script for plotting the convergence of the Bott index under open boundary conditions

### Requirements

- MATLAB (tested with R2023)

### How to reproduce

1. Open MATLAB in this directory.
2. Run the scripts: `SKX_LCM_average` and `SKX_BOTT_average`
